# Front-End

> Aplicação Web responsiva construída com Next.js e React para fornecer a interface visual do sistema Fazenda Urbana através do Design System "Warm Canvas".

## 🎨 Layout e Telas
O Front-End engloba as interfaces para visualização de dashboards de telemetria, gerenciamento de estoques (com alertas de validade), mapeamento de safras, painel de administração e módulos de vendas. Tudo isso protegido por sistema de rotas focado em perfis de acesso (RBAC).

## 🛠 Tecnologias e Bibliotecas
- Next.js (App Router)
- React
- TypeScript
- Recharts

## 🚀 Como Rodar o Front-End
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
